# MGWS Inventory documentation

MGWS Inventory uses your WordPress site as its only backend: no separate
server or database is needed. It sends no data to the developer; bugs and
requests are reported as
[GitHub issues](https://github.com/Vincenzoferrara/mgws-inventory/issues).

## For shop staff

- [User guide](user-guide.md): every screen and the daily procedures.
- [Installation](installation.md): downloads, requirements and the first
  login.
- [Configuration](configuration.md): every settings tab.
- [Troubleshooting](troubleshooting.md): common problems and how to fix
  them.
- [Glossary](glossary.md): the terms used in the app and in these guides.

## For developers

- [Developer guide](developer-guide.md): setup, coding rules, translations,
  theme, builds and releases.
- [Architecture](architecture.md): folders, the login chain, the MGWS
  connection state and the main modules.
- [Integrations](integrations.md): WooCommerce, the MGWS REST API and the
  other services the app talks to.
- [Security](security.md): credentials, logs and privacy rules.

## Rules for this folder

- The guides describe how the app works **today**. They are not a backlog
  and hold no history of changes: release notes go in the GitHub releases.
- A change to a screen, a setting, a flow or an integration updates the
  matching guide in the same commit.
- The guides are in English.
